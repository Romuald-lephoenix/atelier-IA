🛡️ Checklist IA Saine

Les 3 Commandements pour utiliser l'IA sans risque

① TRANSPARENCE

Informer vos clients et collaborateurs de l'usage IA dans vos processus.

  • À FAIRE
  • Mentionner l'usage IA dans votre politique de confidentialité
  • Prévenir votre client si vous utilisez l'IA pour traiter sa demande
  • Documenter où l'IA est utilisée dans votre processus
  • Informer votre équipe des outils IA approuvés
  • À NE JAMAIS FAIRE
  • Utiliser l'IA en cachette sans en informer personne
  • Prétendre que tout est fait manuellement si l'IA a aidé
  • Ignorer les demandes de vos clients sur l'usage de leurs données

② CONSENTEMENT

Demander la permission avant de mettre les données personnelles dans une IA.

  • À FAIRE
  • Obtenir l'accord écrit avant de traiter les données perso en IA
  • Permettre aux gens de refuser d'utiliser une IA
  • Proposer une alternative sans IA si demandé
  • Anonymiser les données avant analyse IA
  • À NE JAMAIS FAIRE
  • Envoyer un email client "Cher Jean Martin" directement dans une IA
  • Mettre les noms, emails, SIRET ou téléphones sans protection
  • Supposer que le consentement est donné juste parce qu'on utilise un service

③ SÉCURITÉ

Protéger les données sensibles avec des outils validés par votre entreprise.

  • À FAIRE
  • Utiliser des outils professionnels/enterprise pour les données sensibles
  • Vérifier la politique de confidentialité de l'outil IA
  • Stocker les données sensibles localement ou dans vos serveurs
  • Chiffrer vos données en transit
  • À NE JAMAIS FAIRE
  • Copier/coller des données clients dans ChatGPT grand public
  • Utiliser un compte perso pour du travail professionnel sensible
  • Oublier que ce que tu envoies peut rester sur les serveurs

📋 Données à NE JAMAIS mettre dans une IA

❌ INTERDITS (100%)

  • Noms, prénoms, emails de clients
  • Numéros de téléphone (même anonymisés)
  • SIRET, SIREN, numéro d'entreprise
  • IBAN, numéro de CB, données de paiement
  • Données médicales ou santé
  • Données RH confidentielles (salaires, évaluations)
  • Contrats signés ou confidentiels
  • Secrets d'affaires ou recettes

✓ AUTORISÉ (avec prudence)

  • Données anonymisées ou pseudonymisées
  • Données publiques (articles, blog, sites web)
  • Informations génériques (secteur, taille d'entreprise)
  • Textes brouillons personnels non sensibles
  • Questions de connaissance générale
  • Code informatique non-propriétaire
  • Demandes de rédaction/reformulation

🎯 Quel Outil pour quel Cas ? (Version 2026)

Données RH, contrats, données sensibles
→ Mistral Enterprise/Vibe Enterprise (hébergement UE) OU Claude for Work/Enterprise
Données professionnelles sans confidentialité max
→ Claude Pro (30j de conservation) OU ChatGPT Business/API (pas d'entraînement)
Brouillons perso / idées / réseaux sociaux
→ Tous les outils ok (comptes perso acceptés)
Recherche web + données pros
→ Claude Pro (contexte 200k) OU Gemini Workspace (si Google)
Code propriétaire / données hautement sensibles
→ Mistral Enterprise (open source possible) OU déploiement local auto-hébergé

Le consentement des personnes doit être explicite et documenté. Cette checklist est un guide pédagogique, pas un conseil juridique. En cas de doute, consultez votre service juridique ou un expert RGPD.
