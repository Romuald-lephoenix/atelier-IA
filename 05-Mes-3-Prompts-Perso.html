🚀 3 Prompts Prêts à l'Emploi

Copy-Paste pour les PME/Freelances

💡 Comment ça marche : Chaque prompt ci-dessous est prêt à copier-coller dans votre IA. Remplissez les [CROCHETS] avec vos infos et c'est parti. Adaptez selon votre contexte.
✍️ Prompt 1 : Reformulation Pro
Idéal pour : Transformer un brouillon/idée en texte professionnel.
Usage : emails clients, posts LinkedIn, propositions commerciales, brouillons.
Le Prompt (à Copier)
Tu es un expert en rédaction professionnelle et copywriting. Mon secteur : [e-commerce / services / digital / autre] Mon audience : [dirigeants PME / clients grand public / décideurs IT] Ton général : [formel / chaud / direct / éducatif] Voici mon brouillon : [colez votre texte brut ici] Tâche : - Reformule en 3 versions = 3 styles différents - Version 1 = formel et rassurant - Version 2 = énergique et commercial - Version 3 = amical et conversationnel Format : chaque version en max 200 mots, avec CTA claire. À chaque réponse, commence par 🐦
Pourquoi ça marche : Ce prompt utilise la méthode R.C.T.F.E. (Rôle = expert, Contexte = votre secteur/audience, Tâche = reformuler, Format = 3 versions, Exemples = style).
💡 Conseil : Une fois les 3 versions, demandez : "Quel ton résonne le plus avec mes clients ? Affine le style vainqueur." Itération = clé du succès.

📋 Adaptations Rapides :

Email client difficile : Remplacez "3 styles" par "1 version ferme mais bienveillante"
Post LinkedIn : Format = "150 car max, avec hook choc en début"
Pitch investisseurs : Ton = "data-driven, 0 émotion, focus ROI"
💌 Prompt 2 : Email de Relance (Client Inactif)
Idéal pour : Reconquérir un client qui ne répond plus.
Usage : clients 3-6 mois inactifs, devis non signés, leads abandonnés.
Le Prompt (à Copier)
Tu es un expert en relation client et reconquête. Contexte client : - Nom/pseudo : [Client A / Jean / Prospect] - Secteur : [le tien] - Dernier contact : [3 mois ago / 6 mois / "jamais répondu à mon devis"] - Raison probable d'inactivité : [budget serré ? changement / équipe ? pas prioritaire ?] Tâche : Crée 2 versions d'email de relance personnalisé - Version 1 = humble et service-first (offre une aide gratuite) - Version 2 = assertif et FOMO (dernière chance avant archivage) Format : - Chacun : max 150 mots - Structure : accroche personnelle → problème/bénéfice → micro-CTA - Ton : professionnel, pas désespéré À chaque réponse, commence par 🐦
Pourquoi ça marche : Les 2 approches couvrent les 2 cas : soit il faut le réengager doucement, soit le pousser. L'IA génère les deux.
💡 Conseil : Après réception, demandez : "Affine la Version 1 avec 1-2 micro-services gratuits que je peux proposer". Spécificité = plus de réponses.

📋 Adaptations Rapides :

Devis non signé : "Problème probable = prix. Propose une version light/allégée."
Lead jamais converti : "Raison = manque de confiance. Ajoute une social proof (cas client)."
Client VIP perdu : "Version 1 = très personnalisé. Version 2 = offre exclusive."
🔍 Prompt 3 : Analyse Concurrence Rapide
Idéal pour : Comprendre vos concurrents rapidement.
Usage : benchmark, positionnement, stratégie tarifaire, points de différenciation.
Le Prompt (à Copier)
Tu es un analyste stratégique spécialisé en [votre secteur]. Contexte : Je suis [votre positionnement], ciblant [votre cible]. Tâche : Analyse ces 2-3 concurrents : 1. [Nom concurrent 1] → [son URL ou sa description] 2. [Nom concurrent 2] → [son URL ou sa description] 3. [Nom concurrent 3] → [son URL ou sa description] Pour chacun, identifie : - Positionnement principal (en 1 phrase) - Offres clés (3-4 points) - Points forts visibles - Points faibles/opportunités pour moi - Tarification si visible Format : tableau ou sections claires. Ajoute une section synthèse = "Où je dois me différencier" À chaque réponse, commence par 🐦
Pourquoi ça marche : L'IA analyse rapidement avec recherche web. Elle synthétise et propose des angles de différenciation. Très utile avant relancer sa stratégie.
💡 Conseil : Après réception, demandez : "Sur les 3 points où je suis fort, génère-moi un messaging qui capitalize dessus". Continue la chaîne d'itération.

📋 Adaptations Rapides :

Benchmark tarifaire : Focus = "Tarification : modèle (abonnement? à l'acte?), prix d'entrée, prix premium"
Analyse contenu : Focus = "Thèmes blog, fréquence publication, type contenu (tuto/avis/success stories?)"
Analyse communication : Focus = "Ton, messaging clé, promesses principales, qui ils ciblent vraiment"

🎯 Comment les Utiliser (Workflow)

Étape 1 : Copiez le prompt complet dans votre IA (Claude, ChatGPT, ou autre)
Étape 2 : Remplissez les [CROCHETS] avec VOS informations
Étape 3 : Collez votre contexte/document si demandé
Étape 4 : L'IA répond. Relisez et adaptez (jamais 100% prêt à utiliser)
Étape 5 : Itérez : "Plus court", "Ajoute [chose]", "Ton moins [truc]"
Étape 6 : Utilisez le résultat + vérifiez les faits importants
⚠️ Important : Ces prompts sont des bases. Chaque utilisation doit être adaptée à votre contexte spécifique. Ne mettez JAMAIS de données sensibles (noms clients réels, SIRET, données RH) sans anonymiser d'abord. Testez en compte personnel avant d'utiliser en professionnel avec des données réelles.
