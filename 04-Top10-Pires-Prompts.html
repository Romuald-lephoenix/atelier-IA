🚫 Top 10 Pires Prompts

Erreurs Courantes & Comment les Corriger

📢 Contexte : Ces 10 erreurs sont les plus fréquentes quand on débute avec l'IA. Chaque exemple montre le MAUVAIS prompt → le BON prompt → la leçon à retenir.
1 Le Prompt Flou

❌ MAUVAIS

Problème : Trop générique, pas de contexte
Aide-moi avec mon email

✓ BON

Solution : Contexte + Tâche précise
Tu es un consultant senior. J'ai un client énervé depuis 3 jours. Crée 3 versions d'un email d'excuses professionnel : une formelle, une chaleureuse, une directe. Format : max 150 mots chacune, avec CTA claire.
📚 Leçon : "Aide-moi" donne 1000 réponses différentes. Ajoute Rôle + Contexte + Tâche + Format. L'IA devient 5x plus utile.
2 Le Prompt Trop Long & Embrouillé

❌ MAUVAIS

Problème : Trop d'infos à la fois, pas de structure
Donc voilà j'ai un projet qui est assez compliqué et j'aimerais que tu m'aides à organiser ma stratégie marketing et aussi à trouver des idées de contenu pour mes réseaux sociaux parce que actuellement je ne sais pas vraiment comment commencer et j'ai pas beaucoup de temps non plus et mon budget est limité et je dois cibler les femmes de 30 à 50 ans et aussi peut-être les hommes aussi du coup voilà j'aimerais que tu me proposes quelque chose qui marche bien voilà

✓ BON

Solution : Diviser en 2 demandes claires
DEMANDE 1 : Rôle = stratège marketing. Contexte = PME services, budget €1k/mois, cible femmes 30-50 ans. Tâche = 3 piliers stratégie marketing 2026. Format = 1 page, structurée. DEMANDE 2 : Rôle = community manager spé LinkedIn. Tâche = 4 idées contenu premium adaptées. Format = titre + 3 bullet/idée.
💡 Conseil : Attends la réponse 1, puis demande 2. Sinon utilise numérotation claire.
📚 Leçon : L'IA peut se perdre dans les textes trop longs. Dividez les gros projets en sous-tâches numérotées.
3 Le Prompt avec Données Sensibles

❌ MAUVAIS

Problème : Donnéesrisk RGPD + données perso exposées
Analyse ces 3 clients : - Jean Dupont, jean@email.fr, SIRET 123456789, revenu 150k - Sarah Martin, sarah@corporate.fr, SIRET 987654321, CA 500k - Pierre Bernard, pierre@startup.fr, SIRET 555555555, revenu -50k Qui est en difficulté ?

✓ BON

Solution : Anonymiser + seules infos nécessaires
Analyse ces 3 profils anonymisés (Client A, B, C) : - Client A : Services, revenu annuel 150k, stable depuis 3 ans - Client B : Tech, CA 500k, croissance 30%/an - Client C : Startup, déficitaire depuis création (-50k/an) Quels signaux de risque tu detects ? Quelles actions recommandes-tu ?
⚠️ RGPD Alert : Jamais noms + emails + SIRET directs. Utilisez des alias (Client A, Prospect 1, etc) + données génériques.
📚 Leçon : Anonymisez TOUJOURS avant de mettre des données dans une IA publique. Contacter votre DPO en cas de doute.
4 Le Prompt qui Suppose un Format

❌ MAUVAIS

Problème : Pas de format spécifié, résultat aléatoire
Comment gérer un client difficile ?

✓ BON

Solution : Format précis
Comment gérer un client difficile ? Format : 5 tactiques claires. Chacune = titre + 2 lignes d'explication + exemple concret. Ton : professionnel, actionnable, bienveillant. Longueur totale : max 500 mots.
📚 Leçon : "Format" change TOUT. Spécifiez : nombre de points, longueur, structure (liste/tableau/paragraphes), ton.
5 Le Prompt sans Itération

❌ MAUVAIS

Problème : On repart de zéro à chaque fois
Prompt 1 : "Crée 3 posts LinkedIn" [IA répond] Prompt 2 : "Ajoute des chiffres aux posts" [L'IA recrée les 3 posts de zéro, et oublie les détails]

✓ BON

Solution : Ajouter Canarie + itération
Prompt 1 : "Crée 3 posts LinkedIn. À chaque réponse, commence par 🐦." [IA répond : "🐦 Voici les 3 posts..."] Prompt 2 : "Ajoute des chiffres/stats au post 2" [IA répond : "🐦 Voici le post 2 enrichi..."] ← Contexte gardé !
📚 Leçon : Utilisez le Canarie 🐦 pour que l'IA se souvienne. Sinon c'est comme expliquer le contexte à quelqu'un de nouveau à chaque fois.
6 Le Prompt qui Suppose une Compréhension Implicite

❌ MAUVAIS

Problème : Trop d'implicite, références confuses
Adapte le plan pour notre machin cette année

✓ BON

Solution : Explicite + Document si possible
Rôle = stratège d'entreprise. Contexte = PME SaaS, 50 salariés, budget 2027 en hausse 20%. Tâche = adapter le plan marketing 2026 (ci-joint) pour 2027. Focus = acquisition 3x + retention. Format = document structuré, sections avant/après, avec ROI estimé. [Puis collez le plan 2026]
📚 Leçon : L'IA n'a pas le contexte implicite. Nommez clairement : qui, quoi, quand, où, pourquoi.
7 Le Prompt qui Demande de Tricher

❌ MAUVAIS

Problème : Demande malhonnête
Invente-moi des chiffres de croissance convaincants pour mon pitch au banquier

✓ BON

Solution : Utilise les vrais chiffres
Rôle = consultant stratégie financière. Voici mes vrais chiffres 2025 : CA 500k, croissance 15%, marge 30%. Tâche = présenter ces chiffres au banquier de façon optimiste mais honnête. Format = structure pitch : marché → positionnement → chiffres clés → projection 2027 conservative.
⚠️ Important : Les faux chiffres = fraude. Délit pénal. L'IA peut vous aider à présenter vos vrais chiffres mieux.
📚 Leçon : L'IA n'invente pas les faits pour vous. Elle reformule, améliore, mais avec vos vrais données.
8 Le Prompt qui Oublie de Vérifier

❌ MAUVAIS

Problème : Pas de vérification, hallucinations
Donne-moi 5 études scientifiques sur l'impact du marketing digital. [L'IA invente des titres convaincants mais faux] [Vous les citez au banquier] [Banquier googlise = arnaque détectée]

✓ BON

Solution : Demander sources vérifiables
Donne-moi 5 études sur l'impact marketing digital. Instructions : - Cite uniquement des sources réelles (Google Scholar, MIT, Harvard Business Review) - Donne le titre exact, l'auteur, l'année - Je vais vérifier chaque source [Puis vous vérifiez sur Google Scholar / site de la revue]
💡 Verbe clé : Demander "Cite tes sources" force l'IA à être + rigoureux.
📚 Leçon : L'IA peut halluciner avec confiance. Toujours vérifier : chiffres, noms, études, faits importants.
9 Le Prompt qui Demande l'Impossible

❌ MAUVAIS

Problème : Demandes hors limites IA
Connecte-toi à mon CRM et mets à jour tous les clients

✓ BON

Solution : Demandes réalistes
Crée un script CSV de mise à jour client. Rôle = data engineer. Input = liste clients existants + nouvelles données. Output = fichier CSV avec colonnes : ID | Nom | Email | Segment | Mise à Jour. [Vous exécutez le script dans votre CRM manuellement]
📚 Leçon : L'IA ne se connecte pas à vos systèmes en live. Elle génère des plans/scripts/templates que VOUS exécutez.
10 Le Prompt sans Feedback

❌ MAUVAIS

Problème : Accepter la première réponse
Crée un plan marketing [IA répond] [Vous prenez tel quel sans feedback]

✓ BON

Solution : Itération active
Crée un plan marketing [IA répond] [Vous dites : "Plus focus ROI, moins théorie. Ajoute budget par canal"] [IA v2] [Vous dites : "Perfecto mais ajoute timeline Gantt mois par mois"] [IA v3 = final]
💡 Le secret : L'itération est CLEF. Chaque "Refais ça + précis" rapproche de votre besoin exact.
📚 Leçon : La 1ère réponse = base, pas finale. C'est comme un brouillon : relisez, réagissez, améliorez.

✅ Les 10 Règles d'Or pour Éviter Ces Pièges

  1. Soyez spécifique : Donnez Rôle + Contexte + Tâche + Format
  2. Divisez les gros projets : Une demande par prompt
  3. Anonymisez vos données : Jamais noms/emails/SIRET directs
  4. Précisez le format : Nombre de points, longueur, structure
  5. Utilisez le Canarie 🐦 : Confirme que l'IA mémorise le contexte
  6. Soyez explicite : Ne supposez pas que l'IA comprend l'implicite
  7. Restez honnête : Utilisez les vrais chiffres, ne trichez pas
  8. Vérifiez les faits : Hallucinations possibles sur données/chiffres
  9. Demandez du réaliste : L'IA génère du contenu, n'accède pas à vos systèmes
  10. Itérez activement : Chaque réponse = base pour le feedback suivant
